## Python build tool

`hatchling` is the existing build backend in `pyproject.toml`. It is not pinned there or recorded in
`uv.lock`. No version is claimed here; changing the build requirement is outside this task.

## Runtime tools

Python 3.12 via uv is the project runtime. SQLite uses the Python standard library.
Optional: llama.cpp `llama-server` and a Qwen GGUF model. Set the endpoint in the local settings.

## Environment variables

Provider keys come only from GEMINI_API_KEY, GROQ_API_KEY and NVIDIA_NIM_API_KEY.
Never put key values in settings or source files.

Use `uv sync --locked` only when installs are authorized.
